# Sistema de Calificaciones Escolares

Programa básico en **C++** que permite ingresar los datos de un estudiante, registrar tres calificaciones, calcular su promedio y determinar su estado académico.

## Niveles

* **Nivel 1:** Estructura básica, variables, `cin`, `cout` y cálculo del promedio.
* **Nivel 2:** Condicionales `if-else` y validación de edad y calificaciones.

## Tecnologías

* C++
* Visual Studio Code
* Git y GitHub
